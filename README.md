# Bankist — When Banking Meets Minimalist

A clean and modern banking landing page built with HTML, CSS, and JavaScript. This project showcases a professional fintech-style homepage with smooth scrolling, sticky navigation, interactive tabbed content, animated testimonials, lazy-loaded images, and a modal signup form.

## Preview

Open the project in your browser to explore the interface:

- `index.html`

For a local preview, you can run a lightweight web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Minimalist banking landing page design
- Sticky navigation with smooth scroll behavior
- Hero section with product messaging and CTA buttons
- Interactive operations tabs
- Responsive layout for mobile and desktop screens
- Testimonial slider with navigation buttons and dots
- Lazy-loaded images for better performance
- Modal popup for account signup
- Scroll-based reveal animations using Intersection Observer

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/yalagandhalajaswanth-collab/Bankist-When-Banking-meets-Minimalist.git
```

2. Navigate to the project folder:

```bash
cd Bankist-When-Banking-meets-Minimalist
```

3. Start a local server:

```bash
python -m http.server 8000
```

4. Open `http://localhost:8000` in your browser.
